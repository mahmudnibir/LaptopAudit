# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability.

Use GitHub's private vulnerability reporting for this repository when available. Include:

- a clear description of the issue;
- affected file(s) or component(s);
- reproduction steps or a proof of concept;
- the potential impact; and
- any suggested mitigation.

LaptopAudit is designed to run locally and avoid telemetry. Reports can still contain sensitive device information such as model, serial numbers, OS details, and hardware identifiers. Treat generated reports as potentially sensitive data and review them before sharing.

## Scope

Security concerns involving the collector, report generation, local storage of physical-check notes, scripts, or repository dependencies are in scope.

Please do not submit real device serial numbers, private reports, credentials, or other personal data in public issues or pull requests.
